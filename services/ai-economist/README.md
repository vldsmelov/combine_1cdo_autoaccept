# AI Economist Service

FastAPI-сервис, который позволяет загружать бюджет организации и проверять документы/реестры закупок на соответствие доступным лимитам.

## Быстрый старт

```bash
# локальный запуск (требуется Python 3.11)
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

После старта API доступно по адресу `http://localhost:8000`.

## Основные эндпоинты

| Метод | Путь | Назначение |
|-------|------|------------|
| `GET` | `/health` | Проверка готовности сервиса. |
| `GET` | `/budget` | Список идентификаторов ранее загруженных бюджетов. |
| `POST` | `/budget` | Загрузка/обновление бюджета. Принимает JSON с идентификатором бюджета и таблицей категорий. |
| `GET` | `/budget/{budget_id}` | Возврат сохранённого бюджета с учётом объединения дублей категорий. |
| `POST` | `/analyze` | Проверка списка покупок в рамках выбранного бюджета. Возвращает детальный отчёт и текстовое резюме. |

### Формат бюджета

```json
{
  "budget_id": "2025",
  "categories": [
    {"name": "Оргтехника", "limit": 1200000, "reserved": 200000, "spent": 400000},
    {"name": "Оргтехника", "available": 600000},
    {"name": "Электроника", "available": "2 000 000"}
  ]
}
```

Категории с одинаковыми названиями объединяются, а доступная сумма автоматически считается по формуле `limit - reserved - spent`, если поле `available` отсутствует.

### Формат запроса на анализ

```json
{
  "budget_id": "2025",
  "items": [
    {"name": "Поставка МФУ Canon iR", "amount": "750 000"},
    {"name": "Сервер HP ProLiant", "amount": 1200000, "description": "для ЦОД"}
  ]
}
```

В ответе приходит JSON со списком категорий, статусом покрытия бюджета и текстовым резюме для пользователя.

## Структура каталога `app`

- `main.py` — точка входа FastAPI.
- `models.py` — Pydantic-схемы и логика объединения категорий бюджета.
- `budget_store.py` — простое хранилище загруженных бюджетов в памяти.
- `matcher.py` — эвристики сопоставления закупок и категорий.
- `summary.py` — генерация текстового резюме по результатам проверки.
- `utils.py` — вспомогательные функции (нормализация текста, парсинг сумм).

## Тестовые сценарии

Сервис рассчитан на работу в Docker и не требует внешних зависимостей. Для юнит-тестов можно использовать `pytest`:

```bash
pytest
```

Тесты лежат в каталоге `tests/`.
