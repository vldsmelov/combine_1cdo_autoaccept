# Архитектура сервисов

Этот документ описывает общие архитектурные принципы, к которым были приведены FastAPI-сервисы платформы. Цель рефакторинга — обеспечить единообразие подходов и облегчить сопровождение.

## Базовые элементы

Каждое приложение строится вокруг одинакового набора компонентов:

1. **`application.py`** — фабрика FastAPI-приложения. Здесь создаётся контейнер зависимостей и инициализируется объект `FastAPI`.
2. **`dependencies.py`** — функции и провайдеры зависимостей, используемые в обработчиках.
3. **`api/`** — модуль маршрутов. Пакет содержит регистратор `register_routers` и папку `routes/` с тематическими роутерами.
4. **Контейнер `AppContainer`** — dataclass, агрегирующий настройки, клиенты и сервисы. Экземпляр контейнера сохраняется в `app.state.container` и доступен зависимостям.

## Жизненный цикл запроса

1. Запрос попадает в конкретный роутер в `api/routes/*`.
2. FastAPI вызывает зависимости из `dependencies.py`, извлекая нужные сервисы из контейнера.
3. Логика обработчика обращается к доменному сервису (например, `ExtractionPipeline`, `ChecklistService` или `LegalAIService`).
4. Ответ сериализуется с помощью Pydantic-схем и возвращается клиенту.

## Преимущества схемы

* **Прозрачность** — все зависимости собраны в одном месте и документированы.
* **Повторное использование** — новые маршруты подключают готовые зависимости без знания внутренней инициализации.
* **Тестируемость** — контейнер легко подменить в юнит-тестах, инжектируя фейковые сервисы.
* **Единообразие** — разработчик, знакомый с одним сервисом, легко ориентируется в остальных.

## Стартовые события

При необходимости сервисы регистрируют хук `on_startup` через вспомогательные функции (например, Legal AI). Это позволяет централизованно управлять ресурсами (подключения к БД, прогрев моделей) и не смешивать инфраструктурный код с обработчиками запросов.

## Обработка ошибок

Каждый сервис использует Pydantic-модели ответов и собственные исключения. Общая структура позволяет вынести обработку ошибок в единый модуль, если понадобится.
