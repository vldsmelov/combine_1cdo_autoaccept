# AI Economist

Сервис экономического контроля, который сопоставляет позиции закупок с бюджетными категориями и проверяет наличие доступных лимитов.

## Основные компоненты

| Путь | Назначение |
|------|------------|
| `app/main.py` | FastAPI-приложение: эндпоинты загрузки бюджета и анализа закупок. |
| `app/models.py` | Pydantic-схемы и утилиты для объединения дублей категорий, нормализации сумм. |
| `app/matcher.py` | Эвристический классификатор, сопоставляющий позиции с бюджетными категориями. |
| `app/budget_store.py` | Простое in-memory хранилище загруженных бюджетов. |
| `app/summary.py` | Формирование человеко-читаемого резюме по результатам проверки. |
| `tests/test_analysis.py` | Юнит-тест сценария загрузки бюджета и анализа закупок. |

## Поток обработки `/analyze`

1. **Загрузка бюджета.** Клиент предварительно отправляет таблицу с лимитами через `POST /budget`. Категории с одинаковыми названиями объединяются, складываются доступные суммы.
2. **Классификация позиций.** Каждая запись закупки нормализуется и сопоставляется с категорией бюджета по ключевым словам и совпадениям.
3. **Агрегация по категориям.** Суммируется требуемый объём средств, вычисляется признак «хватает ли».
4. **Формирование отчёта.** Возвращается JSON с детальными данными и текстовое резюме в формате, близком к примерам для экономистов.

## Расширение

* Для добавления новых правил сопоставления допишите словарь `DEFAULT_SYNONYMS` в `matcher.py` или реализуйте свой класс `CategoryMatcher`.
* Если потребуется постоянное хранилище, замените `BudgetStorage` на реализацию с БД и внедрите её через зависимость.
* Формат ответа можно расширять, не ломая обратную совместимость, добавляя новые поля в `AnalysisResponse`.
